### Proyectos destacados
 
#### 🍽️ [MenuQR: pedidos desde la mesa con código QR](https://github.com/MikelSkate/menuqr)
Los clientes escanean el QR de su mesa y piden desde el móvil sin instalar nada. Cada artículo se envía automáticamente a la pantalla de **cocina** o de **barra**, y el dueño gestiona la carta, las mesas y los alérgenos desde un panel de administración.
- API REST en capas (controller → service → repository) con Spring Boot y Spring Data JPA.
- Tests unitarios de todos los servicios con JUnit 5 y Mockito, y JavaDoc generado.
- 🎥 [Vídeo de demostración](https://youtu.be/EUSJQI3XBOo)
