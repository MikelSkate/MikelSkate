### Proyectos destacados

#### ⏱️ [Control horario para hostelería](https://github.com/MikelSkate/[NOMBRE_REPO])
Aplicación de registro de jornada para empresas de hostelería, con una PWA para los empleados y un panel de administración.
- Arquitectura **multi-tenant** con Spring Boot 3.3, MySQL y migraciones con Flyway.
- Registros de fichaje **solo de inserción** encadenados con **hash SHA-256**, de modo que cualquier manipulación de los registros se puede detectar.
- Sistema de diseño propio con reglas documentadas.

`Java` `Spring Boot` `MySQL` `Flyway` `JavaScript` `PWA`

#### 📅 [Planificador de turnos con optimizador](https://github.com/MikelSkate/[NOMBRE_REPO])
Generador automático de cuadrantes de turnos para hostelería.
- Motor en dos fases: una solución inicial **greedy** que después se refina con **Late Acceptance Hill Climbing (LAHC)**.
- Restricciones duras basadas en el **Estatuto de los Trabajadores** (descansos, jornada máxima, etc.).
- Multi-tenant, con rangos de fechas configurables y validación semanal.

`Java` `Spring Boot` `MySQL` `Algoritmos de optimización` `JavaScript`

#### 🏥 [Clinplates: CRM modular para clínicas](https://github.com/MikelSkate/[NOMBRE_REPO]) · *en desarrollo*
Proyecto de fin de grado en equipo: un CRM SaaS para clínicas de fisioterapia en el que cada clínica contrata solo los módulos que necesita (CRM, citas, base de datos de pacientes).

`Java` `Kotlin` `JavaScript` `SaaS`

#### 🌅 [Portfolio personal](https://github.com/MikelSkate/[NOMBRE_REPO])
